# 架构决策记录

本目录保存已经接受或正在评审的跨模块架构决策。

ADR 记录“决定了什么、为什么、约束和后果”，不替代目标架构或单次 Task。

状态：

- `proposed`：等待产品或架构确认；
- `accepted`：后续实现必须遵守；
- `superseded`：已被新的 ADR 替代；
- `rejected`：明确不采用。
